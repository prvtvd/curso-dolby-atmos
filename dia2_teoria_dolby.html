Sección 01

Numeración de inputs: Bed y Object

El Renderer recibe hasta 128 pistas de audio. Los primeros 10 inputs están siempre reservados para el Bed, sin importar cuántos canales uses realmente. A partir del input 11 entran los Objects.

128 inputs del Renderer — distribución fija
Inputs 1–10 · Bed (siempre reservados)
Inputs 11–128 · Objects (hasta 118)
Inputs adicionales
BED — inputs 1–10
Canal fijo
  • Ocupa inputs 1–10 (formato default: 7.1.2)
  • Sin metadata de posición dinámica
  • Se reproduce en el canal exacto asignado
  • Ideal para ambientes, reverbs, LFE
  • Logic Pro, Cubase y Studio One: solo un Bed
OBJECT — inputs 11–128
Audio con posición
  • Primer Object → input 11
  • Hasta 118 objects simultáneos
  • Lleva OAMD: posición X/Y/Z + tamaño
  • El Renderer ubica el sonido en el espacio
  • Ideal para diálogos, efectos, elementos en movimiento
Múltiples Beds: cada Bed adicional más allá del primero resta inputs disponibles para Objects, ya que el total siempre es 128. Además, hay una sola configuración de Binaural Render Mode por canal de Bed — si cambias el modo del canal L de un Bed, cambia ese canal en todos los Beds definidos.

Sección 02

OAMD y OAR — dos procesos distintos

Dolby Atmos maneja el audio de Objects mediante dos procesos separados: uno ocurre durante la mezcla y el otro durante la reproducción.

OAMD — Object Audio Metadata
Presente durante la mezcla. Captura la información de posición (X/Y/Z) y tamaño de cada Object en tiempo real a medida que se realizan cambios. Se graba como automatización dentro de la sesión y viaja empaquetada con el audio en el master file.
OAR — Object Audio Renderer
Presente durante la reproducción. El dispositivo del oyente utiliza el OAR para reproducir el mix Dolby Atmos completo, adaptándolo al sistema de reproducción disponible: auriculares, home theater, cine, auto, etc.

Sección 04

Binaural Render Mode

Además del OAR que maneja las salidas a altavoces, el Renderer incluye un Binaural Renderer separado para monitorear en auriculares. Aplica dos tipos de procesamiento combinados: HRTFs (Head-Related Transfer Functions) para posicionar el audio, y un modelo de sala que produce reflexiones según la distancia — haciendo que el sonido se perciba fuera de la cabeza.

Es metadata de programa: el Binaural Render Mode se escribe en el master file completo, no por sección. Se usa durante la codificación al codec AC-4 IMS para dispositivos Android y algunas aplicaciones iOS.

Cuatro modos disponibles — clic para ver detalles

Modo
Off
Panning solo por nivel, similar a un pan estéreo convencional. La posición X se comporta como un control de balance.
Modo
Near
HRTF preciso que simula la posición desde el Object hasta los oídos del oyente. Sin simulación de sala.
Modo
Mid
Near + simulación suave de sala. Agrega cues de distancia sutiles preservando el timbre del Object.
Modo
Far
Similar a Mid pero con simulación de sala más pronunciada — mayor sensación de distancia del oyente.
ModoHRTFSimulación de salaUso típico
OffNoNoElementos que no requieren espacialización
NearSíNoBatería, percusión, elementos con impacto inmediato

FarSíPronunciadaGuitarras/synths con reverb, elementos de fondo
Buenas prácticas: distribuir Objects equitativamente entre Near, Mid y Far. Para acercar un Object al oyente sin que "se despegue de la pared" en altavoces, usar Near — funciona en auriculares sin sacrificar la mezcla en altavoces. En general es preferible panear Objects cerca del borde del cuarto virtual.
Atención con múltiples Beds: hay una sola configuración de Binaural Render Mode por canal de Bed. Si defines tres Beds y cambias el canal L del primero a Near, ese cambio se aplica al canal L de los otros dos Beds también.

Sección 05

Re-renders / Channel-based exports

Re-renderizar es el proceso de generar salidas channel-based desde un Dolby Atmos Renderer. Permiten mezclar en Atmos sin necesitar mezclas separadas para deliverables legacy en 5.1, estéreo, etc.

DAW con Renderer integrado
Re-renders disponibles: Binaural, 2.0, 5.1, 5.1.2, 5.1.4, 7.1 y 7.1.4. Generalmente se hacen como operación de export offline.
Renderer App (externo)
Agrega anchos adicionales hasta 9.1.6 y la posibilidad de usar grupos para generar re-renders de stems personalizados (DX, MX, FX, M&E, etc.). En real-time o export offline.
La estrategia Atmos First: un solo mix Atmos puede generar todos los deliverables channel-based en un solo pass de exportación: mezcla completa, Beds, Objects o grupos personalizados. Esto elimina la necesidad de mezclas separadas para cada formato.
Re-renders en el lab (Día 3): configuraremos Loudness Re-Render = 5.1 y Headphone Re-Render = Binaural en el Renderer integrado de Pro Tools. Veremos los re-renders en funcionamiento con Aux tracks.

Sección 06

Input Configuration: nombres y grupos

La configuración default del Renderer asigna los primeros 10 inputs a un Bed 7.1.2 y los 118 restantes como Objects. Esta configuración se puede personalizar para organizar Beds y Objects en grupos — útil especialmente en post-producción.

Ejemplo: workflow de post-producción con stems

Dialog Objects + Dialog Bed → DX Stem — Dialog
FX Objects + FX Bed → FX Stem — Effects
Music Objects + Music Bed → MX Stem — Music
Para música: la mayoría de proyectos usan un solo Bed 7.1.2 compuesto (reverbs, delays y LFE), con todos los instrumentos como Objects. El Bed compuesto alimenta los inputs 1–10 del Renderer.
Grupos standardCódigoUso
DialogDXDiálogos en post-producción
MusicMXMúsica
EffectsFXEfectos de sonido
NarrationNRNarración / voz en off
Logic Pro y Cubase: no permiten múltiples Beds ni grouping de inputs. Solo soportan un único Bed 7.1.2.

El Renderer App y algunos DAWs permiten asignar nombres descriptivos a Beds y Objects. Esos nombres se escriben en el master file y son muy útiles al reimportar un ADM BWF, ya que permiten identificar qué contenía cada track.

Theater vs Person

En el Object View del Renderer hay dos perspectivas para visualizar dónde están los Objects en la sala:

🏛 Theater
Vista aérea de la sala — como un plano de planta. La posición de los Objects se muestra según su ubicación real en el espacio. Es la vista más usada durante la mezcla. Doble clic = vista completamente aérea (overhead).
🧑 Person
Vista desde la perspectiva del oyente sentado en el centro de la sala. Útil para verificar la altura y posición de los Objects en relación directa a la experiencia auditiva.
En el Object View también se puede mostrar: números de Object (para correlacionar con el panner del DAW), configuración de Binaural Render Mode por Object (Near/Mid/Far), y membresía a grupos estándar (DX, MX, FX, NR).
